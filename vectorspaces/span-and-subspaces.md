# Span and Subspaces

## 1. Introduction

Span and subspaces are fundamental concepts in linear algebra.

Span describes all possible vectors that can be generated using linear combinations of a given set of vectors.

A subspace is a subset of a vector space that is itself a vector space.

## 2. Span of Vectors

The span of vectors is the set of all possible linear combinations of those vectors.

For vectors \(v_1,v_2,\ldots,v_n\):

\[
\operatorname{Span}(v_1,\ldots,v_n)
=
\left\{
c_1v_1+\cdots+c_nv_n
\mid c_i\in\mathbb{R}
\right\}
\]

### Example

Consider:

\[
v_1=[1,0],\quad v_2=[0,1]
\]

Their span is:

\[
a[1,0]+b[0,1]=[a,b]
\]

Since every vector in \(\mathbb{R}^2\) can be represented this way:

\[
\operatorname{Span}(v_1,v_2)=\mathbb{R}^2
\]

## 3. Subspaces

A subspace is a subset of a vector space that satisfies three conditions:

1. Contains the zero vector.
2. Closed under vector addition.
3. Closed under scalar multiplication.

### Example

Consider the set:

\[
W=\{(x,y)\in\mathbb{R}^2:y=0\}
\]

This represents the x-axis.

It contains the zero vector and remains closed under addition and scalar multiplication.

Therefore, it is a subspace of \(\mathbb{R}^2\).

## 4. Examples of Subspaces

- The zero vector space.
- A line passing through the origin.
- A plane passing through the origin in \(\mathbb{R}^3\).
- The entire vector space itself.

A line or plane that does not pass through the origin is not a subspace.

## 5. Python Implementation Using NumPy

```python
import numpy as np

# Two vectors
v1 = np.array([1, 0])
v2 = np.array([0, 1])

# Linear combination
a = 3
b = 4

result = a * v1 + b * v2

print("Linear Combination:", result)
```

### Calculate the Span Dimension

```python
A = np.column_stack((v1, v2))

rank = np.linalg.matrix_rank(A)

print("Dimension of Span:", rank)
```

## 6. Span and Subspace Relationship

The span of any set of vectors is always a subspace of the vector space containing those vectors.

For example:

- One nonzero vector in \(\mathbb{R}^2\) spans a line through the origin.
- Two linearly independent vectors in \(\mathbb{R}^2\) span the entire plane.
- Two dependent vectors in \(\mathbb{R}^2\) span a line or the zero subspace.

## 7. Applications

### Machine Learning
- Understanding feature spaces.

- Studying the column space of matrices.

### Data Science
- Finding the space generated by datasets.

### Quantum Computing
- Describing the space of possible quantum states.
- Representing states as combinations of basis vectors.

## 8. Conclusion

Span describes the set of vectors generated by linear combinations, while a subspace is a vector space contained within another vector space.

Both concepts are important for understanding basis, dimension, matrix rank, and linear transformations.
